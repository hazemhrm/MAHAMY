# مهامي | MAHAMY

**Powered by HRM™**

مساحة شخصية لتنظيم المهام اليومية والتذكيرات والوقت والجدول الدراسي.

## التقنية
- HTML5 وCSS3 وJavaScript
- واجهة عربية RTL متجاوبة
- LocalStorage لحفظ البيانات محلياً دون حساب

## حالة التنفيذ
- [x] المرحلة الأولى: الهيكل الأساسي والهوية البصرية والتنقل.
- [x] المرحلة الثانية: إدارة المهام والأولويات والتصنيفات والملاحظات والحفظ المحلي.
- [ ] المرحلة الثالثة: التذكيرات والإشعارات.
- [ ] المرحلة الرابعة: الجدول الدراسي ومراجعة الجمعة.
- [ ] المرحلة الخامسة: التقويم والإحصائيات والإعدادات.
- [ ] المرحلة السادسة: PWA والاستيراد والنسخ الاحتياطي والاختبارات النهائية.

## ما يعمل حالياً
- إضافة المهام وتعديلها وحذفها وإكمالها وإعادة فتحها.
- تواريخ المهام والتسليم والأوقات والتصنيف والأولوية والملاحظات والتكرار كبيانات محفوظة.
- البحث والفرز وعروض اليوم والغد والقادمة والمتأخرة والمكتملة وعالية الأولوية.
- إدارة التصنيفات وإعادة تسميتها وحذفها.
- إنشاء الملاحظات وتعديلها وحذفها وتثبيتها والبحث فيها.
- حفظ المهام والملاحظات فورياً في LocalStorage.
- تنظيف المهام المكتملة بعد 24 ساعة من إكمالها.
- تصدير نسخة JSON احتياطية.

## التشغيل
افتح `index.html` في متصفح حديث أو انشر المستودع على استضافة HTTPS. التخزين المحلي خاص بالمتصفح والجهاز؛ احتفظ بنسخة احتياطية دورياً.

> التذكيرات والتنبيهات الخلفية والجدول الدراسي المتكرر لم تُنفّذ بعد، وستُضاف في مراحلها المحددة.
