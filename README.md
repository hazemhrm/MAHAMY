# مهامي | MAHAMY

**Powered by HRM™**

مساحة شخصية لتنظيم المهام اليومية والتذكيرات والوقت والجدول الدراسي.

## التقنية الحالية
- HTML5
- CSS3
- JavaScript
- واجهة عربية RTL متجاوبة
- تخزين محلي عبر LocalStorage (سيُفعّل مع تنفيذ وحدات البيانات)

## حالة التنفيذ
- [x] المرحلة الأولى: الهيكل الأساسي والهوية البصرية والتنقل بين الأقسام.
- [ ] المرحلة الثانية: المهام والملاحظات والتخزين المحلي.
- [ ] المرحلة الثالثة: التذكيرات والإشعارات.
- [ ] المرحلة الرابعة: الجدول الدراسي ومراجعة الجمعة.
- [ ] المرحلة الخامسة: التقويم والإحصائيات والإعدادات.
- [ ] المرحلة السادسة: PWA والنسخ الاحتياطي والاختبارات.

## التشغيل
افتح `index.html` في متصفح حديث. بعض ميزات الويب مثل الإشعارات والتثبيت تحتاج إلى تشغيل الموقع عبر HTTPS أو localhost.

> المشروع يُنفّذ على مراحل؛ الأقسام التي لم تُنفّذ بعد تظهر بوضوح ولا تدّعي أنها تعمل.
